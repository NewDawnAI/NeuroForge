# Docs Index

NeuroForge documentation is organized into 5 strata, each serving a different audience and purpose. Use this map to avoid reading in the wrong order.

## Start Here
- `00_README_ROOT/` — entry point for first-time serious readers

## Running Examples
Many docs show example commands like `.\build\neuroforge.exe ...`. The exact binary path depends on how you built:
- Single-config generators: `.\build\neuroforge.exe`
- Multi-config (Visual Studio): `.\build\Release\neuroforge.exe` (or `Debug`)

## New: N‑Series Harnesses (N4–N7)
The N‑series harnesses are auditable closed-loop tests for prediction, attention, regulation, and bounded action selection:
- `04_EXPERIMENTS/N_SERIES_HARNESSES.md`
- Post‑N7 promotion gates (shadow→live inside bounded environments): `05_STATUS_AND_ROADMAP/documentation_roadmap/POST_N7_PROMOTION_CHECKLIST.md`

## The Five Strata
- `01_FOUNDATION/` — why this approach exists (mental model, assumptions, philosophy)
- `02_ARCHITECTURE/` — what exists structurally (modules, flows, responsibilities)
- `03_MECHANISMS/` — how learning/adaptation actually happens (advanced)
- `04_EXPERIMENTS/` — evidence (results, failures, validation, logs)
- `05_STATUS_AND_ROADMAP/` — reality anchor (what works, what doesn’t, next steps)

## Archive
- `90_ARCHIVE/` — superseded or exploratory material (not part of the recommended reading path)
